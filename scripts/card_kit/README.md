# Post image system

Every post gets its own header images, and no image is ever used twice.

## How a post gets its images

`scripts/generate_post.py` asks Claude for a scene (`IMAGE_SCENE`) alongside the article, then calls
`image_system.choose_hero()`:

1. **Photo, only when it fits.** A Pexels photo is considered only if the category is Watch Guides,
   Troubleshooting, Installation Guides or Sports Streaming, *and* the scene is one allowed for that
   category (for example `router-cabling` for a buffering fix). Streaming Services, Devices, News and
   Reviews always get a card, because stock photos there tend to show other companies' logos or imply
   hands-on testing.
2. **A candidate must pass every check:** not already used by any post or in the ledger; Pexels' own
   description of the photo matches the scene (at least two keywords, no brand, logo or app names, at
   least 1600px wide); the scene has not been used in the last 6 photos; and no more than one
   photo with people in the last 3.
3. **Photos are downloaded and self-hosted** (`assets/images/posts/`), so the live site never loads
   images from Pexels. The photographer credit is written to `header.caption`.
4. **Otherwise a brand card** is generated by `scripts/image_cards.py` from the site's own product icons.
   Each card has a fingerprint (layout, mirrored or not, palette, icon set) and a fingerprint can never be
   reused. Icons are chosen from the post title (a Wi-Fi fix gets router and cable icons; a remote
   problem gets a remote).

Both routes write three files per post (`<slug>-hero.jpg` 1600x800, `-teaser.jpg` 600x400, `-og.jpg`
1200x630), add `overlay_image`, `teaser` and `og_image` to the front matter, and record the choice in
`_data/image_ledger.yml`.

No `PEXELS_API_KEY` means every post simply gets a card.

## Checks

`scripts/check_posts.py` (runs on every PR) fails if two posts share an image, a header image is really a
different format from its extension, a social or logo image is used as a header, a file in
`assets/images/posts/` is missing from the ledger, a photo has no credit caption, or two cards share a
fingerprint. Older posts that still hotlink Pexels produce one summary warning.

## Maintenance

- **Replace a post's image:** delete its three files and its entries in `image_ledger.yml`, then run
  `python3 -c "import sys; sys.path.insert(0,'scripts'); import image_cards as c; print(c.make_card('<slug>', '<title>', '<Category-Slug>', []))"`
  and point the front matter at the new files (or just let a future change regenerate it).
- **Add or change a product icon:** edit the SVG in `assets/images/products/`, then re-render the PNGs with
  `node scripts/card_kit/render_icons.js` (needs Playwright with Chromium; the PNGs are committed so CI only
  needs Pillow). Add keywords for it in `ICON_KEYWORDS` in `image_cards.py`.
- **Retired images:** `_data/image_ledger.yml` -> `retired` lists the 39 old teaser-pool images that were removed
  (watermarks, third-party logos, irrelevant) and why. Restore any from git history if you disagree.
- **Font:** cards use Inter Bold (`fonts/Inter-Bold.otf`, SIL Open Font License, licence text alongside).
