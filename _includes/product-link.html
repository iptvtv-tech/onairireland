Usage, inside a sentence: {% include product-link.html id="fire-tv-stick-4k" text="Fire TV Stick 4K" %} `text` is the visible link text (defaults to the product name). If the id is not in products.yml, only the text is shown; scripts/check_affiliate_links.py flags unknown ids. Keep this file free of line breaks outside the comment so the link stays inline in Markdown paragraphs, lists and tables.
